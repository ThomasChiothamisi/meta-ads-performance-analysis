# meta-ads-performance-analysis
SQL and Power BI analysis of Meta advertising campaign performance, focusing on engagement, conversions and purchasing behaviour.

SQL Analysis

The SQL analysis uses SQL Server to examine campaign performance, user engagement, conversions and purchasing behaviour across the dataset.

Key areas include:

- Click Through Rate
- Conversion Rate
- Performance by Country
- Performance by Target Gender
- Total Clicks
- Total Enagements
- Total Impressions

[View SQL Query Screenshots](./SQL%20Queries)

Power BI Analysis

Interactive Power BI visualisations are used to present key findings and performance trends from the analysis.
